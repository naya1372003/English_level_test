# 📝 English Level Test | اختبار تحديد مستوى اللغة الإنجليزية

A modern and interactive web application designed to estimate your English proficiency level (from A1 to C1) based on a 15-question multiple-choice test.
تطبيق ويب حديث وتفاعلي مصمم لتقدير مستوى إتقانك للغة الإنجليزية (من A1 إلى C1) بناءً على اختبار مكون من 15 سؤالاً متعدد الخيارات.

## 🚀 Features | المميزات
- 15 comprehensive questions | 15 سؤالاً شاملاً.
- Progress Bar | شريط تقدم يوضح مكانك في الاختبار.
- Instant Visual & Audio Feedback | تفاعل بصري وصوتي فوري (أخضر للصح، أحمر للغلط).
- Dynamic Level Estimation | تقدير المستوى (A1, A2, B1, B2, C1) بناءً على النتيجة النهائية.
- Modern UI/UX | واجهة مستخدم عصرية (Glassmorphism) متجاوبة مع جميع الشاشات.

## 🛠️ Technologies | التقنيات المستخدمة
- **HTML5**: For the structure.
- **CSS3**: For styling, animations, and Glassmorphism design.
- **JavaScript (Vanilla)**: For logic, DOM manipulation, and state management.
- **Web Audio API**: For generating sound effects without external audio files.

## 🧠 What I Learned | ماذا تعلمت
- Managing application state (Current Question, Score) | إدارة حالة التطبيق.
- Dynamic DOM manipulation | التعديل الديناميكي على عناصر الصفحة.
- Building logic for quizzes and score calculation | بناء المنطق البرمجي للاختبارات وحساب النتائج.
- Using the Web Audio API to generate sounds | استخدام واجهة برمجة الصوت لتوليد المؤثرات الصوتية.

## 💻 How to Run | كيفية التشغيل
Open `index.html` in any browser, or visit the live demo on GitHub Pages.
قم بفتح ملف `index.html` في أي متصفح، أو قم بزيارة الرابط المباشر على GitHub Pages.
